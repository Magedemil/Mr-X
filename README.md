# 🔷 HEXA CODE — عصابات مستر X

كل مواد فعالية "Mr. X" لمؤتمر **HEXA CODE** — مؤتمر شباب ثانوي، صيف ٢٠٢٦.
أسرة ثانوي • كنيسة الأميرين تادرس بجاردنيا

## الفكرة باختصار

شخصية غامضة اسمها **Mr. X** — الشباب (3 خلايا استخبارات) بيحلوا مهمات على مدار يومين عشان يكتشفوا مين هو. كل نقطة بيكسبوها بتكشف جزء من **QR code مشفَّر** على شاشة النقاط. لما التحقيق يوصل 100%، الفريق الكسبان بيمسح الكود على المسرح في حفلة السمر — والكود بيفتح فيديو النهاية اللي بيكشف إن Mr. X **فكرة مش شخص**.

## الملفات

- **`mrx-app.html`** — تطبيق لوحة النقاط + الـ QR التدريجي (يفتح في أي متصفح، يعمل بدون إنترنت بعد التحميل)
- **`mrx-script-final.md`** — السكريبت الكامل: فيديو الافتتاح + المهام + حفلة السمر
- **`hexa-code-concept.md`** — تطوير الفكرة: الميكانيكية، قواعد خفة الوزن، الإيقاع، اقتراحات إضافية
- **`promo-videos/`** — برومبتات Higgsfield للفيديوهات الترويجية قبل المؤتمر (بدون كشف فكرة القبعات)

## استخدام التطبيق

افتح `mrx-app.html` مباشرة في المتصفح، أو ارفعه على Vercel/GitHub Pages للوصول من أي جهاز.

- كلمة مرور المشرف: `mission2026`
- من إعدادات المشرف: حدد **رابط فيديو النهاية** (اللي الـ QR هيفتحه) و**إجمالي نقاط اكتمال التحقيق**
- القبعة المفقودة اليومية والأيام بتتظبط من نفس الإعدادات
